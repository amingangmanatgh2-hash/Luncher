# 🎮 NEON RUSH — نئون راش

یک بازی سه‌بعدی مسابقه‌ای/تیراندازی در شهر نئونی سایبرپانک که همان سورس واحد آن در مرورگر، APK اندروید و نسخهٔ ویندوزی **`setup.exe`** اجرا می‌شود.

## ▶️ بازی‌کردن

### روی ویندوز (setup.exe)

1. در GitHub Actions وارد اجرای **Windows** شو و آرتیفکت **`neon-rush-windows-setup`** را دانلود کن.
2. ZIP را باز کن و **`setup.exe`** را اجرا کن.
3. محل نصب را انتخاب کن؛ میانبر Desktop و Start Menu ساخته می‌شود و در پایان می‌توانی بازی را همان‌جا اجرا کنی.
4. چون این بیلد امضای دیجیتال ندارد، اگر SmartScreen هشدار داد: **More info → Run anyway**.

برای ساخت دستی روی ویندوز:

```powershell
cd windows-game
npm ci
npm run dist
```

خروجی در `windows-game/dist-windows/setup.exe` قرار می‌گیرد.

### روی اندروید

1. فایل `luncher-companion.apk` را از GitHub Actions یا Releases بگیر و نصب کن.
2. بعد از نصب، آیکون جدا‌ی **Neon Rush / نئون راش** روی گوشی ساخته می‌شود.
3. از داخل خود لانچر هم دکمهٔ **🎮 بازی NEON RUSH** در صفحهٔ اصلی وجود دارد.

> بازی کاملاً آفلاین است؛ اینترنت، تبلیغ، اکانت و دانلود دیتا لازم ندارد.

### در مرورگر (کامپیوتر یا موبایل)

از ریشهٔ پروژه:

```bash
python3 -m http.server 8080 \
  --bind 0.0.0.0 \
  --directory app/src/main/assets/game
```

بعد این آدرس را باز کن:

```text
http://localhost:8080/
```

## 🏎️ گیم‌پلی

- شهر نئونی سه‌بعدی با ماشین هاور، نورپردازی، سایه، ذرات سرعت و انفجار.
- از ترافیک و موانع جا خالی بده؛ از نزدیک ماشین‌ها رد شو تا **NEAR MISS** و کمبو بگیری.
- درون‌ها و ماشین‌ها را با لیزر بزن.
- کریستال 💎، نیترو ⚡ و تعمیر ❤ جمع کن.
- هر ۶۵۰ متر وارد Sector جدید می‌شوی؛ سرعت و تراکم دشمن‌ها بیشتر و پالت نئونی شهر عوض می‌شود.
- رکورد، تنظیم گرافیک و وضعیت صدا روی دستگاه ذخیره می‌شود.

## 🎨 گرافیک

در منوی بازی سه حالت وجود دارد:

- **فول 🔥**: رزولوشن بالا، سایهٔ 2048 و همهٔ افکت‌ها.
- **متوسط**: تعادل کیفیت و سرعت.
- **کم**: برای گوشی‌های ضعیف‌تر.

اگر فریم‌ریت هنگام بازی پایین بیاید، بازی یک‌بار به‌صورت خودکار کیفیت را کم می‌کند تا روان بماند.

## 🧱 فنی

- موتور رندر: Three.js r128 — به‌صورت vendored در `assets/game/vendor` تا APK بدون اینترنت کار کند.
- صدا و موسیقی: WebAudio؛ افکت‌ها و لوپ سینث‌ویو به‌صورت procedural ساخته می‌شوند و فایل صوتی خارجی وجود ندارد.
- شهر، بافت ساختمان‌ها، ماشین‌ها و ذرات همگی procedural هستند.
- نسخهٔ وب، APK و Windows از یک سورس واحد در `app/src/main/assets/game` استفاده می‌کنند؛ بستهٔ Electron در `windows-game` هنگام بیلد از همان سورس کپی تازه می‌گیرد و NSIS خروجی `setup.exe` می‌سازد.
