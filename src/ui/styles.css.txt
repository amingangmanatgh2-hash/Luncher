/* ==========================================================================
   NOTE ON THE FILE EXTENSION
   --------------------------------------------------------------------------
   This is plain CSS, stored as `.txt` on purpose.

   The Worker imports it as raw text and inlines it into the document's single
   style element, so the whole panel arrives as ONE document in ONE request with
   no external assets. That is the single biggest lever against Cloudflare's daily request
   budget (docs/limits.md) and the reason the panel still renders when CDNs are
   unreachable.

   esbuild reserves the `.css` extension for its own CSS bundler and applies it
   BEFORE any wrangler Text module rule, so importing `./styles.css` yields an
   object rather than a string. The page then renders the stringified form of
   that object inside the style element: a completely unstyled panel, and not a
   single build error to point at it. The `.txt` suffix is a wrangler default
   Text glob, so it works on every version with no custom rules at all.
   ========================================================================== */

/* ==========================================================================
   Luncher design system
   --------------------------------------------------------------------------
   Everything is hand-written and inlined into the panel document. No Tailwind
   CDN, no Google Fonts, no icon webfont: those are exactly the third parties
   that are slow or unreachable from an Iranian network, and a panel that cannot
   render its own CSS is useless precisely when the user needs it.

   Written RTL-first with CSS logical properties (margin-inline-start,
   inset-inline-end, border-inline-start) so the same rules mirror correctly
   when [dir] flips to ltr.
   ========================================================================== */
